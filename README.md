# 🚀 Gestor de Proyectos (Estilo Monday.com)

Sistema moderno, visual e interactivo de gestión de proyectos, tareas y flujos de trabajo colaborativos inspirado en la experiencia de usuario de **Monday.com**.

---

## 📁 Estructura del Repositorio

```
GestorProyectos/
├── .agents/
│   ├── AGENTS.md            ← Documento Maestro de Contexto (Fuente Única de Verdad)
│   ├── rules/
│   │   └── arquitectura.md  ← Puntero automático para Antigravity / Cursor
│   └── skills/              ← Herramientas y skills especializadas
├── decisions_log.md         ← Bitácora de decisiones técnicas de arquitectura
├── .gitignore               ← Archivos y carpetas ignorados por Git
└── README.md                ← Este archivo
```

---

## 👥 Metodología Multiagente (SDD)

El proyecto se desarrolla bajo el modelo de **Desarrollo Guiado por Especificaciones (Spec-Driven Development)**:

1. **Coordinador:** Diseña arquitectura, planifica sprints, redacta especificaciones en bloques ```` y es el único que realiza commits/deploys.
2. **Implementadores (Frontend / Backend):** Programan las características y escriben las pruebas unitarias/integrales.
3. **Verificadores (Frontend / Backend):** Auditan el código de forma crítica e independiente y ejecutan los tests locales para emitir el veredicto formal.
